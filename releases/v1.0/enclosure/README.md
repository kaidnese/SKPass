# SKPass 外壳 3D 打印模型说明

本目录提供 SKPass 读卡器的开箱即用 3D 打印 `.STL` 模型文件。完整 CAD 原工程（SolidWorks `.SLDPRT` / `.SLDASM`）及通用 `.step` 交换模型见源码仓库根目录的 [`enclosure/`](../../enclosure/) 文件夹。

---

## 方案选型与刷卡特性

项目提供两种外壳设计方案，请根据您主要使用的卡片类型选择打印：

| 方案 | 包含文件 | 刷卡体验与特性对比 |
| :--- | :--- | :--- |
| **全封闭方案** | `全封闭/上外套.STL`<br>`全封闭/下外套.STL`<br>`全封闭/下外套（难取出）.STL` | **外观完整美观，整机全包裹**。<br>⚠️ **缺点**：增加了外壳塑料壁厚，**刷 Classic 卡（M1卡 / 兼容卡 / 自制 CUID 卡）效果不佳**，容易因感应距离不足而读取超时。刷官方原装 Aime 蓝白卡正常。 |
| **半封闭方案** | `半封闭/外套.STL` | 💡 **推荐日常使用**。<br>**露出 PCB 的背面，卡片可以直接贴着天线背面刷**。能极大改善 Classic 兼容卡和弱信号自制卡的刷卡灵敏度与识别率。 |

> [!TIP]
> 全封闭方案中提供了两款下外套模型：
> - `下外套.STL`：标准卡扣松紧度，便于日常拆卸检修。
> - `下外套（难取出）.STL`：卡扣间隙更紧，组装后固定更牢固，不易松动脱落。

---

## 推荐 3D 打印参数

- **建议耗材**：PLA、PETG 或 ABS。
- **层高（Layer Height）**：`0.16mm` ~ `0.20mm`。
- **填充率（Infill）**：`20%` ~ `30%`（网格或陀螺仪填充）。
- **支撑（Support）**：根据切片摆放方向按需开启局部支撑。
